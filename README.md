# Dr. Aghav's Health Clinic Website

A responsive, static website for Dr. Aghav's Health Clinic in Kopar Khairane, Navi Mumbai.

## Open the website

Open `html/index.html` in a web browser. The site uses plain HTML, CSS, and browser JavaScript, so you do not need to install dependencies or start a development server.

Google Fonts and the embedded Google Map require an internet connection. The main page and local images load from the project folder.

## Website features

- Clinic services, doctor profiles, hours, address, and contact information
- Responsive navigation for desktop and mobile screens
- Appointment request form with name, phone, department, date, and time validation
- Doctor booking buttons that select the corresponding department in the form
- Google Maps location embed and directions link

The appointment form displays a review of the entered details in the browser. It does not send or save the request; patients should call **+91 93267 75061** to confirm an appointment.
